# Student Center Demo

This is an unofficial demo/mock student center UI built with Next.js for Vercel. It includes working links and route-based pages, so refresh works on each page.

## Pages

- `/` student center dashboard
- `/grades` term selector
- `/grades/spring-2026` Spring 2026 class grades
- `/grades/fall-2026` Fall 2026 in-progress class list

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Upload this folder to GitHub.
2. In Vercel, choose **New Project** and import the repo.
3. Framework preset: **Next.js**.
4. Build command: `npm run build`.
5. Output directory: leave default.

This project intentionally shows an **UNOFFICIAL DEMO** watermark and notice.
